# Security reporting

Wtop is a development process monitor, not a security boundary or antivirus.
Do not run an unverified download elevated. Public beta artifacts disclose their
signature status and exact hashes; a hash is integrity data, not a trust decision.

Do not post passwords, command arguments, account names/SIDs, environment values,
user paths or memory dumps in public reports. For a suspected vulnerability,
use GitHub private vulnerability reporting **only if the repository exposes it**.
Otherwise open a minimal public issue requesting a private reporting route,
without exploit details or sensitive data. No unverified contact address or
response-time promise is made here.

Optional providers are restricted worker processes, not an authority boundary
against a hostile local administrator. Ordinary use installs no service, driver,
updater or startup task. Safety/ownership defects are beta-blocking when reproduced.
